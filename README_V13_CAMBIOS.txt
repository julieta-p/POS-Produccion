V13 - Remito / detalle de venta desde Estado de cuenta

- Detalle de venta ahora usa la BD pos existente, no ventas.dbo.
- El botón Detalle de venta muestra una pantalla tipo REMITO.
- Incluye cliente, fecha, N.º de venta, productos, cantidades, total,
  cobrado, pendiente de la venta y saldo actual del cliente.
- Imprimir / Guardar PDF abre una versión imprimible en el navegador.
  Desde la ventana de impresión de Windows se puede elegir Guardar como PDF
  para enviarlo al cliente.
- Se mantiene el resto del Estado de cuenta V12.
- No se crean, modifican ni eliminan tablas, vistas ni procedimientos de SQL Server.
